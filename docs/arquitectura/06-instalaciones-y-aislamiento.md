# Instalaciones, capacidades y aislamiento

Una instalación de Hugin configura el mismo núcleo para una persona, autónomo
o empresa.

No cambia el cerebro. Cambian las capacidades, el conocimiento, los datos y
los conectores habilitados.

## Capacidades

- Diario.
- Citas.
- Tareas.
- Hábitos.
- Apuntes.
- Tarifas.
- FAQ.
- Agenda comercial.

## Ejemplos

| Instalación | Capacidades |
|---|---|
| Persona | Diario, citas, tareas, hábitos, apuntes |
| Autónomo | Diario, citas, tareas, tarifas, FAQ |
| Empresa | Tarifas, FAQ, agenda comercial |
| Empresa con dueño | Puerta privada y puerta cliente; mismo núcleo |

## Aislamiento

Cada instalación tiene su propia configuración, ficheros de conocimiento y
base asignada.

Una instalación no puede leer el diario, tarifas, citas ni datos estructurados
de otra instalación.
